ADHITI ARCHITECT WEBSITE

1. Extract this ZIP completely.
2. Open index.html in Chrome/Edge.
3. All supplied photos are already inside assets/images/ and work offline.
4. The first temple image is assets/images/hero-temple.jpg and is used as the full-screen hero background.
5. Gallery contains the supplied work photos.
6. + Add More Photos lets you preview extra photos in the current browser session.

IMPORTANT: Do not move index.html alone. Keep index.html, style.css, script.js and the assets folder together.
